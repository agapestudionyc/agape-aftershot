Everything a shoot needs, from the card to the client.

A complete post-shoot workflow that lives right here on your machine — no cloud, no account, no subscription. Just your photos, staying yours.

Press + to start.

Import & verify Copies the card and checksums every file against it. The card is read, never written — reformat it in camera when the report says every file matched.
Separate projects Finds where one folder divides into the shoots it really holds, reading both the clock and the picture. Confirm the grouping, name them, and each gets its own folder.
Sift Judges focus on the face, not the frame, so a shallow depth of field is never mistaken for a miss. The soft, the blinked and the ruined are set aside for your call — never deleted.
Darkroom A darkroom for the final selection: paste your numbers, work through every frame, or be walked group by group through the near-identical runs. Your picks are saved as you go.

Code the other device will ask for
——————

Asked once per device, then remembered for a month. This computer never asks. On a café or hotel wifi it is the only thing between a stranger on that network and your photographs.

Clearing a phone's cache does not forget the code — that lives in a cookie, and an app added to the home screen keeps its own besides. A new code is what asks everybody again, everywhere, at once. It can only be made from this computer.
